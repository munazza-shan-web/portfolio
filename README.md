# Munazza Shan — Blue Denim Portfolio

Extract the ZIP and open index.html to preview.

Upload all extracted files and the assets folder to your GitHub repository root. Do not upload the ZIP itself.
Enable Settings > Pages > Deploy from a branch > main > / (root).

Keep the assets folder with the website; it contains the illustrated character.
The character uses gentle CSS sway motion, not frame-by-frame typing. Reduced-motion preferences disable animation.
No installation or build required. Fonts load from Google Fonts with system fallbacks.
